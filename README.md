# file-based-db

Файловая база данных «Каталог скинов Dota 2» с графическим интерфейсом на Java (Swing).


## Предметная область

База хранит каталог скинов для героев Dota 2. Запись описывает следующие характеристики предмета: к какому герою он относится, какой у него редкости, сколько он стоит на торговой площадке и можно ли его передавать другим игрокам.

Типичные сценарии использования:

- найти предмет по его уникальному номеру;
- посмотреть все предметы для конкретного героя;
- удалить все предметы героя из каталога;
- обновить цену предмета.

## Структура таблицы

База однотабличная. Таблица `Skin`:

| Поле       | Тип Java  | Роль             | Ограничения                         | Пример               |
|------------|-----------|------------------|-------------------------------------|----------------------|
| `id`       | `int`     | **ключевое поле** | уникальное, > 0                     | `1042`               |
| `name`     | `String`  | название предмета | не пустое, до 40 символов           | `Manifold Paradox`   |
| `hero`     | `String`  | герой             | не пустое, до 30 символов; индексируется для быстрого поиска | `Phantom Assassin` |
| `rarity`   | `String`  | редкость          | одно из значений ниже, до 15 символов | `Arcana`           |
| `price`    | `double`  | цена, $           | ≥ 0                                 | `34.50`              |
| `tradable` | `boolean` | можно ли передавать | `true` / `false`                  | `true`               |

Используется 4 разных типа данных: `int`, `String`, `double`, `boolean`.

### Допустимые значения `rarity`

`Common`, `Uncommon`, `Rare`, `Mythical`, `Legendary`, `Immortal`, `Arcana`

### Пример данных

| id   | name                  | hero             | rarity    | price  | tradable |
|------|-----------------------|------------------|-----------|--------|----------|
| 1042 | Manifold Paradox      | Phantom Assassin | Arcana    | 34.50  | да       |
| 1043 | Bladeform Legacy      | Juggernaut       | Arcana    | 29.90  | да       |
| 2001 | Dragonclaw Hook       | Pudge            | Immortal  | 950.00 | да       |
| 2002 | Feast of Abscession   | Pudge            | Arcana    | 27.00  | нет      |

## Функции

- создание, открытие, удаление, очистка, сохранение БД;
- добавление записи с проверкой уникальности `id`;
- удаление записи по `id` и удаление всех записей по значению неключевого поля;
- поиск по `id` и поиск всех записей по значению неключевого поля;
- редактирование записи;
- создание backup-файла и восстановление из него;
- экспорт в `.xlsx`.


## Сборка и запуск

```
mvn clean package
```
